# Публикация обновлений VPN Pulse Lite

Этот репозиторий содержит **только публичные бинарные релизы**. Исходники приложения, ключи и конфигурации VPN здесь запрещены.

## 1. Включение GitHub Pages

1. Откройте [Settings → Pages](https://github.com/darrtah/vpn-pulse-lite-updates/settings/pages).
2. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
3. Укажите ветку **main** и каталог **/(root)**.
4. Нажмите **Save**.
5. Проверьте адрес `https://darrtah.github.io/vpn-pulse-lite-updates/`.

GitHub Pages должен обслуживать статические файлы из `main`. Файл `.nojekyll` исключает обработку Jekyll.

## 2. Адреса обновлений

- Beta feed: `https://darrtah.github.io/vpn-pulse-lite-updates/beta/latest.json`
- Stable feed: `https://darrtah.github.io/vpn-pulse-lite-updates/stable/latest.json`

**Пока APK не опубликованы, URL feed должны отвечать 404.** Не публикуйте фиктивные manifest, «пустые версии» или APK с непроверенным ключом.

## 3. Подпись

- Для Beta нужен постоянный ключ, совместимый с установленными `ru.vpnpulse.lite.beta`.
- Для Stable нужен постоянный ключ, совместимый с установленными `ru.vpnpulse.lite`.
- Ключ и пароль хранятся только вне публичного Git; перед релизом нужна резервная копия.
- Если прежний ключ неизвестен, **не публикуйте обновление как замену установленной версии**. Потребуется отдельная стратегия миграции.

## 4. Фиксация доверенного сертификата

Перед первой публикацией каждого канала добавьте файл:
- `beta/signing-cert-sha256.txt` — SHA-256 сертификата подписи Beta;
- `stable/signing-cert-sha256.txt` — SHA-256 сертификата подписи Stable.

Запишите ровно **64 символа hex** из `apksigner verify --print-certs` для проверенного ключа.
Сначала сверьте сертификат с уже установленной версией либо согласованным постоянным ключом.
Не копируйте сертификат из непроверенного APK как доказательство доверия.

GitHub Actions автоматически проверяет manifest и файл APK. Если опубликован APK без закреплённого сертификата, проверка завершится ошибкой.
Если APK пока нет, workflow подтверждает только структуру репозитория, **не подпись релиза**.

## 4. Публикация APK

1. Соберите версию с **большим** `versionCode` и правильно встроенным HTTPS URL канала.
2. Подпишите APK постоянным ключом нужного канала.
3. Проверьте подпись через `apksigner verify --verbose --print-certs`.
4. Проверьте обновление на тестовом телефоне, включая сохранение данных.
5. Подготовьте файл `latest.json` в приватном проекте через `tools/prepare_update_release.ps1`.
6. Проверьте `packageName`, `versionCode`, `sha256`, размер и URL файла.
7. Поместите подписанный APK в `beta/` или `stable/` **без перезаписи уже опубликованной версии**.
8. Поместите соответствующий `latest.json` туда же **последним**.
9. Проверьте оба файла по публичному HTTPS. Проверьте обновление из приложения.

**Не выкладывайте в Public артефакт debug-сборки, пока не проверен постоянный ключ подписи.**

## 5. Протокол latest.json

```json
{
  "schema": 1,
  "packageName": "ru.vpnpulse.lite.beta",
  "versionCode": 8,
  "versionName": "1.1.0-beta7",
  "apkUrl": "https://darrtah.github.io/vpn-pulse-lite-updates/beta/vpn-pulse-lite-8.apk",
  "sha256": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
  "sizeBytes": 1000000,
  "notes": "Исправления VPN Pulse Lite."
}
```

Это **образец**, а не действительная опубликованная версия.

APK и feed должны быть на одном HTTPS origin. Приложение отклоняет HTTP, перенаправления, неверный digest, неподходящий пакет, подпись или номер версии.

## 6. Проверки доступности

- Проверьте GitHub Pages без VPN, с Happ и через мобильные сети пользователей.
- Проверьте скачивание APK, а не только `latest.json`.
- Проверьте разрешение Android на установку из Lite и системное подтверждение.
- При недоступности `github.io` в ограниченных сетях используйте другой HTTPS-хост. Не объявляйте доступность на основании тестов одной сети.

## 7. Откат

Оставьте предыдущий APK неизменным. Если новая версия неисправна, прекратите публикацию её manifest.
Понижение `versionCode` штатной установкой Android не допускается. При исправлении выпустите новый APK с **большим** `versionCode`.

Источник исходников: приватный проект VPN Pulse Lite. В этот репозиторий не переносите исходный код или рабочие секреты.
