# VPN Pulse Lite — обновления

Публичный канал для **подписанных APK** VPN Pulse Lite.

Этот репозиторий не содержит исходников приложения, конфигураций VPN, ключей подписи или пользовательских данных.

## Каналы
- `/beta/` — тестовые версии с пакетом `ru.vpnpulse.lite.beta`.
- `/stable/` — стабильные версии с пакетом `ru.vpnpulse.lite`.

На старте оба канала пустые. Файла `latest.json` пока **нет**: обновления не активны.

После настройки GitHub Pages ожидаемые адреса:
- `https://darrtah.github.io/vpn-pulse-lite-updates/beta/latest.json`
- `https://darrtah.github.io/vpn-pulse-lite-updates/stable/latest.json`

Эти адреса начнут выдавать релизы только после публикации настоящих подписанных APK и соответствующих `latest.json`.

## Безопасность
- Не загружайте сюда JKS/keystore, пароли, токены, SSH-ключи, UUID и конфигурации клиентов.
- Каждый APK проверяйте по подписи, имени пакета, `versionCode` и SHA-256.
- Публикуйте APK и `latest.json` только после контрольной установки на телефоне.
- Сохраняйте неизменными имена APK с номером версии; обновляйте `latest.json` последним.
- Стабильный и тестовый каналы **не взаимозаменяемы**.

См. [инструкцию по публикации](PUBLISHING.md).
