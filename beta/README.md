# Beta

Канал тестовых APK для пакета `ru.vpnpulse.lite.beta`.

Здесь пока **нет опубликованного релиза**. Не создавайте `latest.json` без действительного APK и проверки постоянной подписи.

В будущем после проверки появятся:
- `latest.json` — метаданные актуальной Beta;
- `vpn-pulse-lite-<versionCode>.apk` — проверенный APK той же версии.

Документация: [PUBLISHING.md](../PUBLISHING.md).
