# Stable

Канал стабильных APK для пакета `ru.vpnpulse.lite`.

Пока **нет опубликованного релиза**. Рабочую установленную версию нельзя заменять APK с другой подписью.

Здесь появятся `latest.json` и подписанный APK только после проверки обновления с сохранением пользовательских данных.
